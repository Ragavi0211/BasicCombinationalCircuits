# Basic Combinational Circuits

This repository contains basic combinational digital circuits
implemented using Verilog HDL.

## Circuits

- Half Adder
- Full Adder
- Half Subtractor
- Full Subtractor
- Multiplexer
- Demultiplexer
- Encoder
- Decoder
- Comparator

## Tools Used

- Verilog HDL
- Xilinx Vivado
- VS Code
- Git
- GitHub
