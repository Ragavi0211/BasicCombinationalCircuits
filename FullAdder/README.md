# Verilog Basic

This contains my basic Verilog HDL designs and simulations for full adder.
Half Adder is a combinational logic circuit that adds three single-bit binary inputs (a and b and c) to produce a sum (via XOR) and a carry (via AND-OR)

## Tools Used

- Verilog HDL
- Xilinx Vivado
- VS Code
- Git
- GitHub
