# Verilog Basic

This contains my basic Verilog HDL designs and simulations for half subtractor.
Half subtractor is a combinational logic circuit that subtracts two single-bit binary inputs (a and b) to produce a difference (via XOR) and a borrow (via AND and NOT gates)

## Tools Used

- Verilog HDL
- Xilinx Vivado
- VS Code
- Git
- GitHub
